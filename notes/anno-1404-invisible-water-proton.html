Invisible (or black) water in Anno 1404 Venice under Proton

On high graphics settings the water is completely invisible; on low settings it turns solid black. Below you will find my solutions to fix the problem.

Environment

OSArch Linux, Wayland
CPU / GPUIntel Core i9 (13th gen) · NVIDIA RTX 5080
GameAnno 1404 — Venice (Steam AppID 33350)
ProtonGE-Proton 11-3

The fix isn't specific to this hardware — it should apply to any Wine/Proton setup running Anno 1404.

Root cause

1. The DirectX 10 water shaders don't compile

Anno 1404 can run in either DX9 or DX10 mode. Under Wine/Proton its DirectX 10 reflection and refraction shaders fail to compile properly, so the water surface is never drawn — it renders as fully transparent on high settings, or falls back to a black surface on low settings where reflections are disabled.

2. Venice reads a different config directory

This is the part that makes the problem stubborn. The base game and the Venice expansion keep separate configurations:

  • Ubisoft/Anno1404/ — base game
  • Ubisoft/Anno1404Addon/ — Venice

Most guides online tell you to edit Engine.ini, and if you edit the base game's copy, Venice happily keeps running in broken DX10 mode and nothing changes.

The fix

  1. Find your Proton prefix

    The prefix lives under the Steam library the game is installed in. The default location is:

    Default Steam library 
    ~/.steam/steam/steamapps/compatdata/33350/pfx/drive_c/users/steamuser/AppData/Roaming/Ubisoft/

    If you keep games on a second drive, the prefix sits in that library instead (e.g. /mnt/games/SteamLibrary/steamapps/compatdata/33350/). This finds it wherever it is:

    Locate the config directory 
    find / -type d -name Anno1404Addon 2>/dev/null

  2. Force DirectX 9 for Venice

    Open Anno1404Addon/Config/Engine.ini — despite the extension it's XML — and set the DirectX version to 9:

    Anno1404Addon/Config/Engine.ini 
    <DirectXVersion>9</DirectXVersion>
    Watch out

    Make sure you are editing the Anno1404Addon file, not Anno1404. Editing the wrong one is the single most common reason this fix "doesn't work". Do the base game too if you also play it without the expansion.

    The game rewrites Engine.ini when you change graphics options in-game, so re-check this value if the water disappears again later.

  3. Install native DirectX 9 libraries into the prefix

    Wine's built-in d3dx9 implementation is incomplete for what Anno asks of it. Install Microsoft's real d3dx9_*.dll files into the prefix:

    protontricks 
    protontricks 33350 d3dx9

    On a non-Steam / plain Wine install, the equivalent is winetricks d3dx9 with WINEPREFIX pointed at your prefix. The DLLs land in the prefix's syswow64 directory (Anno 1404 is a 32-bit game).

  4. Tell Wine to prefer those libraries

    Installing them isn't enough — Wine still loads its own builtin versions unless you override it. In Steam, right-click the game → Properties → Launch Options, and paste:

    Steam launch options 
    WINEDLLOVERRIDES="d3dx9_24,d3dx9_25,d3dx9_26,d3dx9_27,d3dx9_28,d3dx9_29,d3dx9_30,d3dx9_31,d3dx9_32,d3dx9_33,d3dx9_34,d3dx9_35,d3dx9_36,d3dx9_37,d3dx9_38,d3dx9_39,d3dx9_40,d3dx9_41,d3dx9_42,d3dx9_43=n,b" %command%

    n,b means "native first, builtin as fallback". The %command% placeholder is required — Steam substitutes the actual launch command there.

  5. Delete the broken shader cache

    Anno caches compiled shaders, so it will happily reuse the broken DX10 ones. Empty the fxo directory next to the config so the engine recompiles from scratch on the next start:

    Clear the shader cache 
    rm -rf ~/.steam/steam/steamapps/compatdata/33350/pfx/drive_c/users/steamuser/AppData/Roaming/Ubisoft/Anno1404Addon/Config/fxo/*

    The first launch afterwards takes a few seconds longer while the shaders rebuild. That's expected.

Result

Water, reflections and refraction all render correctly again, at full graphics quality. DX9 mode costs nothing visually here — Anno 1404's DX10 path only ever added minor effects, and the game is old enough that the performance difference is irrelevant on modern hardware.

Still broken?

Check Engine.ini again after launching — if DirectXVersion flipped back to 10, the game overwrote it, so set it once more and avoid touching the in-game graphics options. Also verify the launch options actually applied by confirming the d3dx9_*.dll files exist in the prefix's windows/syswow64/.
